# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's security-advisory
feature for `ariel-ps/herdr-doomface`. Include affected versions, reproduction
steps, impact, and any suggested mitigation.

Do not open a public issue until a fix or coordinated disclosure is ready.
Reports about the downloaded Doom shareware asset should also identify the
source revision and observed SHA-1.

## Supported versions

Security fixes are applied to the latest released version and the default
branch.
